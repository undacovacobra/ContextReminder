# ContextReminder v1.2 Reminder Access Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve location confidence, surface caller reminders over the call UI, and add a four-trigger home-screen quick-add widget.

**Architecture:** Keep the existing rule engine and storage unchanged. Add focused Android components: geocoder search/selection in the add flow, observable geofence registration, a WindowManager call overlay, and AppWidget/QuickAddActivity entry points that reuse existing rule creation behavior.

**Tech Stack:** Kotlin, Jetpack Compose, Android Geocoder, Google Play Services Geofencing, WindowManager TYPE_APPLICATION_OVERLAY, AppWidgetProvider/RemoteViews, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-29-v1.2-reminder-access-design.md`

## Global Constraints
- minSdk 29, targetSdk 36, compileSdk 36.
- Keep all rule data local; add no remote account or API key.
- Existing v1.1 reminder JSON must remain readable.
- Normal notifications remain the fallback for caller reminders.
- Version becomes 1.2.0 / versionCode 3.
